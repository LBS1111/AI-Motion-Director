# 可复用 Motion Pattern

用assets/templates/pattern.json起步，替换所有示例来源与观察。一个Pattern表达一个可复用的信息关系，例如“总览→聚焦”，不要只写“很高级”。

保留purpose、use_when、avoid_when、phases、运动/镜头耦合、阅读停留、调整范围。evidence写真实来源、时间段、observation、inference。implementation可以knowledge-only，说明未来可行的引擎但不要宣称已经完成。

先与已有模式检索比对。同一机制的新证据通过update关联或补充，工具特定实现作为implementation独立记录。是否重复由内容和条件判断，不由名字自动删除。

候选propose后先review，用户确认后approve。复现代码、媒体或实测参数是新的验证证据，更新验证等级同样需要展示变更。收藏是单独偏好，不把“做得好”直接当永久收藏指令。
