# 视频案例学习

先确定用户要学习的范围。视频读取和帧提取为项目草稿操作，入长期库仍须确认。按commands运行extract-video，生成证据清单，原文件保持不变。

## 观察

- 镜头：位置、朝向、目标、是否存在视差；不把主体缩放直接判为Dolly。
- 运动：相对位置、角度、大小随时间变化，是否预备、越过目标或衰减。
- 节奏：行动、制动、停留、信息落点，必要时密集取帧。
- 构图：主角、阅读顺序、前后层级及弱化对象。

必须实际查看序列或视频。GIF使用真实帧延时，不由帧数假设30fps。extract的requested_time是请求采样时间而非精确帧PTS；需要精确测量时结合ffprobe帧时间，给出误差范围。

从渲染画面通常无法确定原软件、弹簧刚度或精确Bezier控制点。记录“观察到回弹”与“推测阻尼弹簧”两层，并附时间段和信心等级。丢帧、压缩、遮挡和低帧率需要降低置信度。

生成机制卡，不复制品牌、文案或完整创作。原视频与帧默认留在项目中，不自动复制进公开仓库或长期素材库。按extract-pattern继续。
