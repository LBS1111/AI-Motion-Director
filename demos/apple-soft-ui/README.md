# Apple Soft UI motion demos

Five original, silent, 4-second films in a restrained gray Apple Soft UI / neumorphic style. Each uses a different camera path and a different object action. These are conceptual motion demonstrations, not recordings of Codex or actual routing and learning operations. The reviewed-learning clip places a visible review step before the reusable rule.

[Watch all five in one 20-second showreel](videos/00_Showreel.mp4).

| Film | Visual idea | Media |
| --- | --- | --- |
| Project name | A raised capsule opens during a short dolly, then contracts. | [MP4](videos/01_AI-Motion-Director_Intro.mp4) · [GIF](previews/01_AI-Motion-Director_Intro.gif) |
| Brief to scene | One tile unfolds into three visual concepts as the camera moves sideways. | [MP4](videos/02_Brief-to-Scene.mp4) · [GIF](previews/02_Brief-to-Scene.gif) |
| Skill routing | Three ability chips follow separate rails into slots; the camera follows and the chips sink into the dock. | [MP4](videos/03_Skill-Routing.mp4) · [GIF](previews/03_Skill-Routing.gif) |
| 2.5D camera | One persistent board has cards at different depths; the camera pans, turns, pushes in, then flies past it. | [MP4](videos/04_2.5D-Camera.mp4) · [GIF](previews/04_2.5D-Camera.gif) |
| Reviewed learning | A reference curve is checked, lifted and transferred to a rule recess during a camera pan. | [MP4](videos/05_Review-and-Learn.mp4) · [GIF](previews/05_Review-and-Learn.gif) |

MP4: 1920×1080, 30 fps, 120 frames, H.264, silent. GIF: 960×540, 15 fps. All five begin and end on an identical neutral surface for looping. PNG posters are in `posters/`.

Editable Remotion source is in [`source/`](source/). In that folder run `npm install` then `npm run render` to rebuild MP4s, or `npm run stills` to rebuild posters. FFmpeg creates GIFs from the MP4s. Rendered media is included for preview and can be used in this repository; no third-party footage or upstream skill code is embedded.
